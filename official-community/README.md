# 官方 Harness 基础上的社区安装版

上游：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)，MIT 许可证。

固定版本 `dsh-v0.1.5-rc.2`，提交 `fb2c4b9e698e30edb738bca4cf0618587db7d203`。
这里保留复现补丁，不把开发者机器的运行时或账户数据提交到 Git。

## 普通用户

从本仓库 Release 下载 `DSH-Desktop-Community-0.1.5-rc.2-Setup-x64.exe` 并双击安装。
Node、pnpm 和首次启动依赖已经封装；不需要打开命令行安装它们。
首次初始化在本地完成，使用模型和查询余额需要联网及自己的 DeepSeek API Key。

## 维护者复现

构建机器需要 Windows x64、Git、Node.js 和 npm；这些要求不适用于安装包的使用者。
运行 `./build.ps1 -BuildDirectory D:\Build\dsh-community`，目标目录必须不存在。脚本固定上游提交、应用补丁、构建官方程序与离线种子，再生成社区安装包。脚本各阶段在本次交付中分别执行过；未声称另一次全新克隆构建已验收。

## 改动范围

- 沿用官方 Electron 外壳、后端通信、离线依赖安装、单实例和事务激活机制。
- 社区版独立应用标识、默认数据目录，不接入官方自动更新，不带官方签名。
- 增加已保存账户的余额查询，使用官方 `/user/balance` 接口，不回传密钥或上游错误正文。
- 每轮回答显示人民币估算费用，展开用量可查看各请求金额；保留原模型、时间和缓存统计。无法确定时显示无法估算。
- 价格表快照为 2026-09-12；当前仅支持已列出的官方 Flash 系列和 V4 Pro。估算不能代替真实账单，价格变化后须更新版本。
- 采用官方应用内目录浏览组件，替代本次故障涉及的 Win32 对话框；为后端、插件安装及 Windows Job runner 的 spawn 设置 windowsHide。

## 验证边界

本机 Windows 11 已验证安装程序退出成功、打包运行时在全新数据目录且 PATH 无 Node 时完成离线安装、真实后端启动和 HTML 加载、第二次启动不重复安装。新增功能与相关回归测试已通过。

尚未完成对方 Windows 10 实机操作、真实付费模型请求和实际账户余额查询，因此以预发布测试版交付。不是 DeepSeek 官方发行包。

`upstream.patch` 可应用到上述原版提交；Release 另附完整修改源码、原版源码、可重建源码归档的二进制补丁、验证记录和回滚脚本。回滚脚本只恢复源码归档副本，不删除用户会话或密钥。
